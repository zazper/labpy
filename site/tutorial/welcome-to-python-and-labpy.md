## How LabPy works

- Write code in the editor and press **Run** (or Ctrl+Enter).
- Python downloads the first time you run something, then it is cached.
- Your files are saved in this browser. Use **Download** to save them to your computer.
- **Format** tidies your code and **Check** finds unused imports and variables.
