> **Version 1.2** | Updated 2026-10-28 | File: `TUTORIAL_TOC_v1.2.md`

Companions: [FEATURES_v1.2.md](FEATURES_v1.2.md), [ROADMAP_v1.2.md](ROADMAP_v1.2.md). The tutorial is organised **by topic** (no chapters or progress tracking yet). The order is a proposal and is meant to be changed.

## How to read this list

- **Level:** B = beginner, I = intermediate, A = advanced.
- **Runs:** *Local* = runs in the browser with no extra downloads. *Package* = loads a library on demand (numpy, pandas, pytest and so on). *Cloud* = the explanation is free to read, but running the samples needs the cloud runner (trial or paid); in the app these samples show a sign-up and trial prompt.
- Every topic has a short write-up and at least one runnable example with a Try it button.

## Topic page template

1. Title and one-sentence summary.
2. Short explanation in plain language (a few paragraphs at most).
3. One to three examples, each with a Try it button (the whole code box is also clickable).
4. Common mistakes (optional).
5. Previous and next topic links.

## Content format (implementation notes)

- One Markdown file per topic under `site/tutorial/<group>/<topic>.md`, with a small header (title, level, runs, order) and code blocks marked as runnable.
- A single `site/tutorial/toc.json` lists groups and topics. Re-ordering the tutorial means editing only this file.
- Topic files load on demand when opened; Python itself loads on the first Try it.
- Cloud samples are shown read-only with a lock and a trial prompt.
- All text and examples are written for LabPy, not copied from other sites.

## How to re-order

Move rows in this document, then update `toc.json` to match, bump the minor version, and add a Document history row.
